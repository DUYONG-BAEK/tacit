5. 모의 엣지 서버 — TacitQEdgeServer (Python)

확정

새 프로젝트 C:\Projects\keenEye\TacitQEdgeServer. Python 3.11(PC 설치 확인됨) + aiohttp 하나로 WebSocket과 대시보드를 한 포트(8765)에서 처리한다. 나중에 실제 AI(OpenCV·PyTorch)를 붙이기 쉬운 구조로 둔다.

구성

파일내용
edge/protocol.pyFRAME 바이너리 해석 · JSON 메시지 생성 (§3과 1:1). pytest 대상
edge/session.py세션 상태: 받은 프레임 수 · fps · 대역폭 · 순번 누락 · 최근 프레임
edge/fake_judge.py가짜 판정기 — 기본 4초마다 부품 1개. 확률 합격 70 · 불합격 20 · REVIEW 10. part_id A_0001부터. 5건 중 불합격 3건 이상이면 PATTERN
edge/server.py/v1/stream(WS) · /(대시보드) · /live.mjpg(받은 영상 그대로 재생) · /stats · POST /judge?verdict=FAIL(강제 판정)
tools/fake_mobile.py폰 없이 시험 — 웹캠 또는 이미지 폴더를 §3 규격으로 송신, 받은 JUDGE 출력
tests/pytest — 규격 왕복 · 세션 통계 · 가짜 판정 순번

대시보드 (브라우저 http://localhost:8765/)

  • 받은 영상 실시간 표시 (폰이 보낸 JPEG 그대로)
  • 통계: 수신 fps · Mbps · 누적 프레임 · 순번 누락 수 · 폰 연결 상태 · session_id
  • 최근 판정 목록 + 버튼 [합격] [불합격] [REVIEW] [연속불량] — 누르면 즉시 해당 JUDGE/PATTERN 회신
  • 자동 판정 켜기/끄기 · 주기 조절

저장 (선택)

--record 옵션 시 recordings/<session_id>/<seq>.jpg로 저장 — 나중에 AI 학습·재현용. 기본은 꺼짐(디스크 보호).

실행

cd C:\Projects\keenEye\TacitQEdgeServer
python -m venv .venv ; .venv\Scripts\activate ; pip install -r requirements.txt
python -m edge.server --port 8765 [--record] [--auto-judge 4]
