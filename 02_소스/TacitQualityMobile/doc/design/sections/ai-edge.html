폰 규칙

항목규칙
영상 송출HMD JPEG를 받는 대로 I420으로 넣는다(쉬는 간격 없음 · 최신 1장만 담는 통로, 밀린 프레임은 버림). 2026-11-09 전에는 "넣은 뒤 100ms 쉼"이라 서버 도착이 초당 6.9장이었다
해상도대역폭이 모자라도 해상도를 낮추지 않는다(maintain-resolution, VP8 4~12Mbps) — QI가 640 타일로 보므로 해상도가 곧 검출력
연결 · 재연결연결 성공 = searching으로 본다. 생존 신호 없음 — disconnected·failed·closed면 새 POST /offer. 간격 1 → 2 → 4 → 5초, 한 번의 시도는 10초 마감. 422·403은 설정 오류로 띄우고 다시 시도하지 않는다. 끊긴 동안 HMD에 "⚠ 서버 지연 · 검사 계속" 띠
끊긴 사이 끝난 제품서버는 disconnect로 기록하고 메시지는 보내지 않는다 → 다시 붙으면 GET /products?station=…&limit=1로 받아 결과 카드로 띄운다
피드백수동 모드: 결과 카드에서 PUT /products/{id}/feedback(source=live). 누르기 전에 다음 제품이 끝나면 카드가 바뀌고 이전 제품은 미입력으로 남는다. 자동 모드: 피드백 없음. 모드는 연결 때 서버에 알리므로 검사 중에는 못 바꾼다
M-05 이력원본은 서버(GET /products, 최신 순 · 50개씩 · 전체/미입력/확인필요/불합격 필터). 상세: 프레임 사진 전부 넘겨 보기(결함 프레임은 상자를 그린 사진), 결함 확대, 피드백 수정(source=history, 누구나 · 변경 기록)
M-06 관리서버 디스크(GET /storage: 남은 공간 · 종류별 · 날짜별). 서버는 사진을 자동으로 지우지 않는다
결함 확대 보기오버레이를 잘라 크게: 겹친 상자 합침, 정사각 한 변 = max(짧은 변 20%, 상자 긴 변 3배), 핀치 확대·이동. 오버레이 404는 0.5초 뒤, 503은 1초 뒤 한 번 더
HMD 연결BLE PING 1초 · SHOW는 순번·ACK(200ms). ACK가 없으면 BLE를 다시 연결하고, 붙으면 지금 화면을 다시 보낸다. HMD는 3초 무소식이면 스스로 수동 판정 화면(H-09). 교대 마감 때는 대기 화면을 보낸 뒤 끊어 장애로 보지 않게 한다
통신 로그상단 바 "로그" → 모바일 ↔ AI 서버 / 모바일 ↔ HMD. 5초마다 "HMD 영상 n장 받음 · 서버로 n장 보냄 · 서버 메시지 수 · 보냄 해상도·fps·제한 사유", HMD 카메라 상태(HELLO). 복사·지우기
