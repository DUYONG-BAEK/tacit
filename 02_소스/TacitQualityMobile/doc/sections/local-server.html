로컬 개발 서버 — 6화면 데이터 API (Ktor + PostgreSQL)

2026-09-20 완료

모바일 화면 6종(M-01~M-06)이 InMemory 샘플에서 벗어나 실제 HTTP + DB로 개발할 수 있도록, 별도 프로젝트 TacitQMockServer에 개발용 모의 백엔드를 세웠다. 운영 서버(타 팀·05 엑셀 관계형 스키마)가 준비되면 대체되는 개발 언블록용 도구다.

설계 판단 — 앱 모델을 복사해 계약 일치

앱의 model/Codes.kt·Entities.kt·data/SampleData.kt가 전부 순수 Kotlin(안드로이드 무의존)인 점을 활용해 서버로 그대로 복사했다. 서버가 내려주는 JSON이 앱의 데이터 클래스와 100% 일치하므로, 나중에 모바일 Retrofit 계약이 정확히 맞아떨어진다. 운영 관계형 스키마(05)는 타 팀 소유라, 여기서는 컬럼 400개 DDL 없이 PostgreSQL JSONB 문서 저장으로 계약만 맞춘다.

진행 내역

  • 프로젝트 골격 — Ktor(Kotlin) + PostgreSQL(Docker) · docker-compose.yml
  • 앱 모델 3파일 복사 — Codes·Entities·SampleData (순수 Kotlin이라 그대로 재사용)
  • Db.kt — PostgreSQL(JSONB) entity(collection,doc_id,data) 시드·조회 (멱등 upsert)
  • Application.kt — Ktor 라우팅. 컬렉션 11종 + /api/users/me + /health
  • Docker PostgreSQL 기동 → 서버 :8081 → 실데이터 검증 완료
