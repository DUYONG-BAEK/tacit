모의 AI 엣지 — WebRTC API 흉내

2026-10-08 진행 중 · 서버 완료, 폰 연동 다음

실제 AI 서버(192.168.1.11:8080)는 사내 Wi-Fi에서만 접속 가능. 사무실 밖에서도 폰 WebRTC 연동(설계서 §9)을 개발·시험하려고 같은 API를 흉내 내는 모의 서버를 엣지 프로젝트에 추가. 근거: A4_WEBRTC_API.md.

계획

  1. 모의 AI 엣지 (TacitQEdgeServer/edge/ai_mock.py) — 이번
  2. 폰 앱 WebRTC 연동 (§9 변경 범위: AiEdgeLink · AiMessages · AiResultsApi · HevcSurfaceDecoder · M-01 설정)
  3. 장비 연결 시 종단 시험: 모의 엣지(집) → 실제 AI 서버(사무실)

진행 내역

  • aiortc 1.15.0 설치 (av 18.1 → 17.1 변경, 기존 HEVC 시험 15건 재통과 확인)
  • API — POST /offer(422 입력 오류 · 403 미등록 스테이션 · ST-01~03) · GET /results/{id} · /mask(PNG) · /overlay(JPEG, 받은 영상 + 빨간 표시) · POST /results/{id}/decision
  • 데이터 채널 흐름 — searching(no_paper) → hold 1~10 (0.2초) → captured → result(OK/NG/REVIEW) → 3초 뒤 반복 · 같은 NG/REVIEW 3연속 → alert
  • 해상도 근사 — 영상 긴 변 < 1920이면 계속 searching(too_small) (종이 긴 변 ≥1216px ÷ 화면 폭 63% ≈ 1920) · --min-long-side 0으로 끄기
  • 대시보드 http://localhost:8080/ — 받은 영상 · 다음 판정 지정(OK/NG/REVIEW) · 자동 순환 켜기/끄기 · 서버 장애(연결 끊기) · 보낸 메시지 기록
  • pytest 6건 추가 (같은 PC 안 aiortc 클라이언트로 실제 WebRTC 연결) → 전체 21건 통과
  • 폰 앱 WebRTC 연동
실행: .venv\Scripts\python -m edge.ai_mock --port 8080 · 폰 설정의 AI 서버 주소를 http://<PC IP>:8080으로. 기존 모의 엣지(WebSocket :8765)는 그대로 유지.
주의: WebRTC는 adb reverse로 안 됨 — 폰과 PC가 같은 Wi-Fi(또는 같은 핫스팟)에 있어야 함. 키즈카페 같은 AP 격리 망에서는 시험 불가.
