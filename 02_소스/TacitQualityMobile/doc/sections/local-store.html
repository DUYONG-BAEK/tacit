C5 LocalStore 구현 — 로컬 이력 + 전송 큐(Room) · V-M04

2026-09-20 완료

조립 순서 3번 C5 LocalStore를 착수·완료했다. 검사 이력과 전송 큐를 휴대폰에 남겨, 서비스가 안드로이드에 의해 언제 종료되어도 재시작 후 이어가게 한다. 핵심 규칙 하나가 V-M04 "유실 0건"을 만든다: 전송 큐(outbox)는 어떤 이유로도 지우지 않는다.

진행 내역

  • 의존성 추가 — Room 2.6.1(runtime·ktx) + KSP 2.0.21-1.0.28(컴파일러), 시험용 Robolectric 4.14.1 · androidx.test.core · coroutines-test
  • store 패키지 신설(kr.co.snail.tacitq.mobile.store) — 4개 파일
  • QmsEntities.kt — inspection(이력) · outbox(전송 큐, id 오름차순=FIFO)
  • QmsDao.kt — put·markSynced·pruneSynced(이력만) / push·nextBatch·ack·queueSize(큐)
  • QmsDatabase.kt — Room DB 싱글턴(파일 tacitq.db)
  • LocalStore.kt — 상태 기계 출력(Effect.Persist·Enqueue)을 즉시 영속화하는 파사드. record()는 이력 저장 + 큐 적재를 한 번에("미동기화 이력은 큐와 짝")
  • V-M04 단위 시험 3건 전부 통과 — Robolectric 으로 실제 Room 을 JVM 에서 검증
