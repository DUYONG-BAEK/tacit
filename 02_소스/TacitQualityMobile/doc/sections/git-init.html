본격 개발 전, 변경 이력·되돌리기 확보를 위해 로컬 Git 저장소를 초기화. 대외비 자료이므로 로컬 전용으로 관리하며, 공개 원격(GitHub 등)에는 절대 올리지 않는다.

진행 내역

  • git init -b main — 로컬 저장소 생성
  • 최초 커밋 69747cf — 소스 35개
  • 빌드 산출물(/build)·서명키(keystore.properties, *.jks) 제외 확인
백업 주의: 현재 로컬 전용이라 PC 디스크 장애 시 유실 위험. 팀 공유·백업이 필요해지면 회사 승인된 사내 원격(사내 GitLab / GitHub Enterprise 등)에만 연결한다. 공개 저장소·개인 클라우드는 금지(대외비).
