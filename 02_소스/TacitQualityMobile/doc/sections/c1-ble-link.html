C1 BleLink — 폰 → HMD 화면 지시(BLE) · 실장비 종단 시험

2026-10-05 완료

엣지 판정 → 폰 상태기계 → BLE → HMD 화면까지 처음으로 끝까지 이어졌다. 상태기계가 만든 SHOW 쪽지가 이제 실제 BLE GATT 로 HMD 에 가고, HMD 는 그려서 ACK 를 돌려준다.
