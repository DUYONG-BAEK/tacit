검사 메뉴(M-01) 정비 · HMD 배터리 · 스테이션 표시

2026-11-11 작성 완료 · 실기기 확인 대기

M-01의 점검 6항목·"HMD" 줄·"모델 · 임계값" 줄은 모두 SampleData 고정 글자였고, 항목을 누르면 무조건 "재점검 — 통과"가 됐다. HMD 배터리는 HMD 앱·폰 앱 어디에도 읽는 코드가 없었다(상태기계 R19는 있었지만 이벤트를 보내는 곳이 없음). 지금 시나리오(AI 서버 판정)에 맞게 실제로 재는 값만 남겼다.

1. 점검 항목 정리

이전 항목처리
제스처 캘리브레이션 (끄덕임 · 가로젓기)삭제 — 서버 POST /decision 없어짐(11-03), HMD 제스처 인식 없음
프레임 게이팅 시험삭제 — 서버가 프레임마다 PD로 제품을 찾는다
트레이 개설삭제 — AI 서버 흐름에 트레이 없음
모델 · 임계값삭제 — 서버가 정한다(앱은 decision만 씀)
HMD 페어링 · 스트림 대역폭 · "HMD" 줄실제 값으로 교체 — 아래 '검사 중 상태'
작업자 · 라인 · 품번삭제 → 스테이션(입력·표시). 품번은 HMD 왼쪽 위 글자로만 쓰였다 → 이제 "● REC · ST-02"

2. 새 M-01

구분내용
시작 전 확인 (필수)스테이션 · AI 서버 주소 입력 / 폰 블루투스 켜짐 / AI 서버 응답(GET /storage 200, 남은 디스크 표시) — 5초마다 다시 확인. 하나라도 안 되면 '검사 시작'이 막힌다. 블루투스 권한은 시작 때 묻고 거부하면 시작하지 않는다(HMD 는 폰 BLE 쪽지가 와야 카메라를 켬). 알림 권한도 함께 묻는다(선택)
검사 중 상태 (막지 않음)HMD 연결(BLE) · HMD 영상 · HMD 카메라(HELLO) · HMD 배터리 · AI 서버(연결 · 보낸 장수, 403 설정 오류) · 서버 진행 · 마지막 제품
연결 설정AI 서버 주소 · HMD 영상 주소(BLE 로 자동, 비상용) · HMD 결함 원 · 모드. 모의 엣지 선택지 제거(DevSettings.edgeKind·edgeUrl, 서비스 분기)

3. HMD 배터리

  • HMD: HELLO 에 battery(%) · charging 추가 (BatteryManager)
  • 폰: HELLO 를 연결 직후 · 영상 끊김 · 30초마다 읽는다(GattBleLink) → 해석 HmdHello → M-01 · M-07 표시, Event.HmdHeartbeat → R19(15% 미만 · 충전 중 아님이면 반장 알림 기록), 부족해질 때 토스트 1번, 통신 로그는 10% 단위로
  • 옛 HMD 앱은 배터리가 없다 → "알 수 없음 (HMD 앱 업데이트 필요)"

4. 하단 탭

수거(M-03 · M-04) · 관리(M-06) 탭 숨김 — 샘플 데이터 화면. 화면 코드는 남겨 둠(AppShell.TABS). 탭: 검사 · 영상 · 이력.
