HMD 앱 착수 — 1단계: 카메라 → 폰 영상 송출

2026-10-01 완료

설계서 ① HMD 앱(촬영·송출)은 원래 "타 팀" 몫이었으나 담당자가 없어, 모바일 팀이 함께 개발하기로 했다. 새 프로젝트 TacitQualityHmd(안드로이드/Kotlin·CameraX)를 만들고, 가장 먼저 "HMD 카메라 영상이 폰으로 전송되는지"를 실제 코드로 구현·검증했다.

왜 우리가 만드나

HMD 앱이 없으면 영상을 찍어 보낼 주체가 없어 검사 루프가 돌지 않는다. 같은 안드로이드/Kotlin이고, 쪽지 규격(§3)·화면 명세(H-01~09)가 이미 확정돼 있어 상대편(모바일 HmdRenderer·ShowWire)과 짝으로 개발 가능하다. "버리는 데모"가 아니라 진짜 제품의 첫 조각이다.

진행 내역 (1단계)

  • 새 프로젝트 TacitQualityHmd 골격 (CameraX · minSdk 29)
  • MainActivity.kt — CameraX 기동, 프레임 → JPEG, 서버 기동, 접속 주소 표시
  • MjpegServer.kt — 외부 라이브러리 없는 multipart/x-mixed-replace MJPEG 서버(:8080)
  • YuvToJpeg.kt — YUV_420_888 → NV21 → JPEG 변환
  • 실장비 검증 성공 — HMD 카메라 영상이 폰 브라우저(http://<HMD-IP>:8080)에서 실시간 표시 (~14fps)

★ RealWear 520 카메라 함정 (해결)

구형(legacy) 카메라 HAL이라 CameraX가 까다로웠다. 카메라가 안 켜지던 원인과 해결:

증상원인해결
ImageAnalysis 단독 → 카메라 안 열림구형 HAL은 Preview 표면 필요Preview 함께 바인딩
Preview 붙여도 프레임 0SurfaceView 표면이 RealWear에서 생성 안 됨TextureView(COMPATIBLE) 모드
그래도 0 → 갑자기 켜짐화면이 실제 렌더링돼야 카메라 시작디스플레이 깨어나니 동작

구글 이슈트래커 295633027(520 ImageAnalysis 문제)와 동일 증상. Preview(TextureView) + ImageAnalysis 조합으로 해결.

검증 경로: HMD·폰을 폰 핫스팟 같은 망에 두고, 폰 브라우저로 HMD IP:8080 접속. MJPEG라 앱 없이 브라우저로 바로 영상이 보인다.
